# AgriSense Pro

Design a premium, modern, startup-quality AgriTech application called "KrishiMitra AI".

Theme:

A clean, professional AI-powered Smart Farming Assistant inspired by Google Material Design 3 with Apple-level minimalism. The interface should feel like a real commercial SaaS product, not a student project.

Primary Colors:

• Deep Green (#2E7D32)

• Light Green (#66BB6A)

• White (#FFFFFF)

• Light Gray (#F5F7FA)

Accent Colors:

• Blue (#1976D2) for AI insights

• Orange (#FB8C00) for warnings

• Red (#E53935) for critical alerts

Typography:

Modern fonts like Poppins, Inter, or Google Sans.

Design Style:

• Rounded cards (16–20px radius)

• Soft shadows

• Glassmorphism for summary cards

• Minimalistic icons

• Smooth animations

• Responsive layout

• Material Design 3

• Premium startup appearance
